# Changelog

## [0.20.0](https://github.com/trvon/yams/compare/v0.19.0...v0.20.0) (2026-09-24)


### ⚠ BREAKING CHANGES

* **plugins:** code-symbol extraction is gone. Removed: the symbol_extractor_v1 plugin ABI, `yams config grammar` (list, download, path, auto-enable, auto-disable), the grammar steps in `yams init`, the meson option `plugin-symbols`, the conan option `enable_symbol_extraction`, and the Windows installer SymbolPlugin component. Databases migrate to schema 41; a v0.19 binary refuses to open them, and symbol data dropped by migration 40 cannot be recovered.
